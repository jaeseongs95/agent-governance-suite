# v2.2.6

오케스트레이터의 기존 규칙을 보존하면서 진입 문서를 줄였습니다. 협업 상세 조건, 독립 숙고·감사 handoff, MCP 실행 계약을 참고 문서 세 개로 분리하고, 각 문서를 읽어야 하는 시점을 본문에 명시했습니다.

- 기존 48개 문단을 본문과 참고 문서에 원문 그대로 보존했습니다.
- 공용 `SKILL.md`는 UTF-8 기준 25,336바이트에서 17,049바이트로 32.7% 줄었습니다. 전체 워크플로의 토큰 사용량이나 구독 한도 절감률을 뜻하지 않습니다.
- 실행 코드의 동작, 라우팅 조건, 스킬 버전, DB 스키마와 브로커 프로토콜은 바뀌지 않습니다. MCP 서버의 플러그인 버전 표기만 갱신했습니다.
- Codex와 Claude Code 배포물에 문서 분리를 반영했습니다.

이전 버전과의 비교 실험은 같은 설정을 상속한 별도 실행자가 12개 합성 요청에 대해 작성한 계획을 독립 판정하는 방식입니다. 실제 도구 실행과 모든 상황에서의 행동 동등성을 증명하는 실험은 아닙니다.
