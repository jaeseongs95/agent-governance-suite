# v2.1.2 — Windows 프로세스 식별 검증 안정화

## 변경

- 프로세스 시작 토큰의 일치·불일치·조회 불가 상태를 병렬 단위 테스트에서 주입값으로 결정적으로 검증합니다.
- 실제 운영체제의 시작 토큰 조회는 별도의 직렬 CI 단계에서 최대 세 번 시도해 한 번 이상 토큰을 얻는지 확인합니다. Windows GitHub Actions의 병렬 테스트 부하가 PowerShell 시작 시간을 5초 제한 밖으로 밀어내면서 제품 결함처럼 보이던 실패를 분리합니다.
- v2.1.1의 NUL 본문 거부와 Windows `Get-Process` 조회 구현은 그대로 유지합니다.

## 알려진 제한

- Windows에서 같은 사용자 권한의 호스트 프로세스 시작 토큰을 훅 제한 시간 안에 읽지 못하면 선택 기능인 세션 메시지 relay는 시작하지 않습니다. 이 경우 기존 스킬과 MCP 기능은 계속 동작합니다.

## 릴리스 관계

- v2.1.1 공개 뒤 Ubuntu Node.js 22·24는 통과했고 Windows Node.js 22·24는 프로세스 토큰 검사를 병렬 suite 안에서 실행해 각각 5초 제한에서 실패했습니다.
- v2.1.2는 운영체제 probe를 직렬 검증으로 분리한 권장 패치 릴리스입니다.
