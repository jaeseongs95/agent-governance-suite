# v2.2.5

위임 결정과 실제 모델 설정의 기록을 정비하고, 작업 기준선이 바뀌었을 때 최종 통합 결과를 우선하도록 지침을 보완했습니다.

- 명시적인 위임 요청은 병렬 속도·비용 이득과 구분해 판단합니다. 독립 완료 가능성, 충분한 컨텍스트와 단일 작성자 조건은 유지합니다.
- 새 위임 결정은 `CollaborationDecision.v1`의 `schemaVersion: 1.1.0`을 사용합니다. 기존 `1.0.0` 결정은 당시 라우팅 의미로 계속 검증합니다. 독립 감사 의무는 구현 위임 여부와 별도로 유지합니다.
- 의존성 설치 없이 실행하는 모델 라우팅 CLI를 포함합니다. 요청한 모델·추론 수준, 실제 전달 인자, 호출자가 관측한 적용 결과와 대체 설정 사유를 구분합니다. 고위험 작업의 모델·추론 하한과 호스트별 컨텍스트 제약을 검사합니다.
- 위임 후에는 조정자가 독립적으로 진행할 수 있는 작업을 계속하도록 안내합니다. 최신 통합 대상에 맞춘 재배치가 총작업 비용을 줄이면 기존 시도 기록과 재사용할 근거를 보존하고 새 대상에서 검증합니다.

Codex와 Claude Code 배포물에 같은 변경을 반영했습니다. 실제 모델 설정 적용과 병렬 실행 여부는 호스트가 제공한 관측 근거 범위에서만 확인할 수 있습니다. DB 스키마와 브로커 프로토콜은 바뀌지 않습니다.
