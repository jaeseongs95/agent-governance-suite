# AGS 3.8.1 릴리스 노트

2026년 11월 7일 공개한 AGS 3.8.1은 3.8.0의 긴급 결함 하나를 고친 수정판입니다. 데이터·공개 API 계약은 바꾸지 않으며 이관 작업은 필요 없습니다.

## 고친 결함

- **AGS3-D-0060**: 하위 에이전트(서브에이전트)가 한 일이 부모 세션의 턴 끝 단계 확인에 부모의 일로 잡혔습니다. 그래서 백그라운드 하위 에이전트를 기다리기만 하는 부모 세션이 Stop마다 「멈추지 말고 남은 작업을 이어서 하라」는 안내로 다시 깨어나 할 일 없는 턴을 반복했고, 안내에는 하위 에이전트가 연 workflow도 섞였습니다.
  - 턴 끝 단계 확인은 그 세션이 직접 한 편집에만 반응합니다.
  - 하위 에이전트가 시작하거나 연 workflow는 부모 세션의 단계 확인 목록에 나오지 않습니다. 결속은 그대로라 하위 에이전트가 그 범위 안에서 하는 편집은 편집 관문을 통과합니다.
  - 하위 에이전트의 편집은 이전처럼 편집 관문(workflow 없는 제품 파일 편집 거부, 파일 수 상한)을 그대로 거칩니다.

## 알려진 제한

- 호스트가 도구 호출마다 하위 에이전트를 알려 주는 Claude Code와 Codex에 적용됩니다. Antigravity는 아직 도구 호출에서 하위 에이전트를 구분할 근거를 받지 못해 같은 증상이 남을 수 있습니다.
