# AGS 3.8.1 릴리스 노트

2026년 11월 7일 프리릴리즈로 공개한 AGS 3.8.1은 3.8.0의 긴급 결함 하나를 고친 수정판입니다. 데이터·공개 API 계약은 바꾸지 않으며 이관 작업은 필요 없습니다.

## 고친 결함

- **AGS3-D-0060**: 하위 에이전트(서브에이전트)가 파일을 고칠 때마다 부모 세션의 턴 끝 단계 확인이 다시 켜졌습니다. 그래서 백그라운드 하위 에이전트를 기다리기만 하는 부모 세션이 Stop마다 「멈추지 말고 남은 작업을 이어서 하라」는 안내로 다시 깨어나 할 일 없는 턴을 반복했습니다. 이제 턴 끝 단계 확인은 그 세션이 직접 한 편집에만 반응합니다. 하위 에이전트의 편집은 이전처럼 편집 관문(workflow 없는 제품 파일 편집 거부, 파일 수 상한)을 그대로 거칩니다.

## 알려진 제한

- 하위 에이전트가 연 workflow는 여전히 부모 세션의 단계 확인 목록에 함께 나옵니다. 부모가 직접 편집한 뒤 턴이 끝날 때만 보이며, 3.9.0에서 구분합니다.
- 이 판은 사용자 지시에 따라 코드 수정을 먼저 내보낸 프리릴리즈입니다. 시험 서버 전체 시험과 회귀 시험은 뒤따라 실행합니다.
