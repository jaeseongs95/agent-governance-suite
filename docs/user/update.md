# 업데이트와 이전

처음 설치는 [README의 설치 절](../../README.md#설치)을 봅니다. 이 문서는 새 판 알림, 업데이트 절차, 언어 패키지 바꾸기, 이전 판에서 올릴 때 확인할 것을 설명합니다.

## 새 판 알림

MCP 서버는 고정된 공개 저장소에서 `vMAJOR.MINOR.PATCH` 형식의 안정 tag만 확인합니다.

- 성공한 확인 결과는 24시간 동안 보관합니다. 확인에 실패하면 마지막 성공 결과를 유지하고 1시간 뒤 다시 시도합니다. 확인 실패는 workflow를 멈추지 않습니다.
- 설치된 판보다 높은 안정 판이 있으면 도구 응답 뒤에 `plugin-update-notice`를 한 번 붙입니다. 같은 판의 알림은 한 번만 나옵니다.
- 직접 확인하려면 에이전트에게 `check_for_updates`를 호출하게 합니다. `force: true`이면 보관한 결과와 관계없이 다시 확인합니다.
- 알림만 할 뿐 플러그인 파일, 설치 캐시, 마켓플레이스 설정을 바꾸거나 자동으로 설치하지 않습니다.
- 스킬을 MCP 없이 직접 호출한 경우에는 업데이트를 확인하지 않습니다.

## 업데이트 절차

1. 사용하는 모든 호스트에서 기존 AGS MCP 서버와 relay를 끝냅니다. 같은 상태 파일을 쓰는 이전 판 프로세스와 새 판 프로세스를 함께 실행하지 않습니다.
2. 각 호스트에 [README의 설치 절](../../README.md#설치)대로 새 판을 설치합니다.
3. 새 세션을 시작합니다. 호스트별로 다음을 합니다.
   - **Claude Code:** 새 세션을 시작합니다.
   - **Codex:** `/hooks`에서 AGS hook을 다시 검토하고 신뢰합니다. 신뢰하기 전에는 hook이 실행되지 않아 턴 안내, 작업 기록, 현황판, 메시지 전달이 동작하지 않습니다.
   - **Antigravity:** 앱을 닫고 새 설치본을 설치한 뒤 앱을 다시 시작합니다. 앱이 켜져 있으면 기존 설치 폴더를 지우지 못해 설치가 실패합니다.
4. 새 판의 릴리스 노트에서 「업그레이드 전 확인」이나 깨지는 변경을 확인합니다.

문제가 생기면 운영 DB와 키를 지우지 않고 보존한 채 조사합니다. 이전 판을 다시 설치하는 것만으로 롤백되지 않을 수 있습니다. 각 판의 되돌리기 방법은 그 판의 릴리스 노트에 있습니다.

## 언어 패키지 바꾸기

호스트마다 한국어 패키지와 영어 전용 패키지가 있습니다. 영어 전용 패키지는 AGS 메시지, MCP 도구 설명, hook 문구, 오류를 영어로 내고, 스킬 본문은 원문(대부분 한국어) 그대로 둡니다. 상태는 같은 위치에 저장되므로 다른 패키지를 다시 설치해 언어를 바꿀 수 있습니다.

**한 호스트에서는 둘 중 하나만 켜십시오.** 둘 다 켜면 Claude Code는 한쪽 hook만 불러오고 Codex는 둘 다 실행합니다.

표시 언어만 바꾸려면 관리자 페이지의 표시 언어를 쓰거나 `AGENT_GOVERNANCE_LOCALE`을 설정합니다. 우선순위는 [관리자 페이지와 컨텍스트](admin-page.md#표시-언어와-편집-관문-예외-경로)에 있습니다.

## 이전 판에서 올릴 때

- **4.0.0:** JEV 설정을 설치 설정 파일·환경 변수에서 관리자 페이지로 옮겨야 합니다. [JEV 4.0.0 이전 절차](admin-page.md#3x에서-400으로-옮기기깨지는-변경)를 따릅니다.
- **3.8.0:** 3.7 이하에서 올릴 때는 작업 기록 DB를 백업하고 이관해야 합니다. [3.8.0 업그레이드와 기존 데이터 이관](migrate-to-v3.8.0.md)을 먼저 따릅니다.
- **3.x와 2.x:** 3.x는 2.x와 호환하지 않습니다. 2.x가 남긴 broker 파일과 `host-id`의 처리는 [상태 저장과 정리](state.md#이전-판이-남긴-파일)에 있습니다.

### Antigravity: 3.0 이전 서버 키

3.0부터 Antigravity의 AGS MCP 서버 키는 `ags`입니다. 3.0 이전에는 `agent-governance-suite`였습니다. 다시 시작한 앱은 새 설정의 서버 키 `ags`만 읽으므로, 이전 서버 키로 띄우던 AGS MCP 서버를 다시 띄우지 않습니다.

이전 서버 키로 설치했던 경우, 새 대화의 시작 hook이 그 키의 도구 스키마 캐시 폴더(`~/.gemini/antigravity{,-cli}/mcp/agent-governance-suite_agent-governance-suite/`)를 같은 디스크의 `~/.gemini/antigravity{,-cli}/ags-legacy-server-key-backup/`으로 옮깁니다. 폴더 안 항목이 모두 agy가 쓰는 도구 스키마 파일일 때만 옮기며, 프로세스는 끝내지 않습니다. 이 결정의 기록은 [AGS3-D-0028 전환 결과](../archive/antigravity-migration.md)에 있습니다.
