# Agent Governance Suite v1.8.0

`v1.8.0`은 반복 실패의 확정 원인에 맞는 복구 방법을 선택하고 새 작업으로 넘기는 `recovery-strategy-selector`를 추가하는 minor 릴리스다.

## 변경 사항

- 복구 전략을 적용 가능성, 사용자 가치 보존, 위험, 복구 가능성과 검증 가능성으로 비교한다.
- 원인이 확정되지 않은 실패에는 전략을 선택하지 않고 추가 진단을 요구한다.
- 선택한 전략과 거절한 대안, 필요한 승인·증거를 `RecoveryHandoff.v1`에 결속한다.
- 이전 실패 작업의 권한을 새 작업 권한으로 승격하지 않고 명시적 task binding을 검증한다.
- 오케스트레이터가 진단과 복구 선택을 별도 단계로 연결한다.

## 호환성과 복구

공개 SQLite schema는 `v1.7.0`과 같다. 문제가 생기면 marketplace ref와 설치 버전을 `v1.7.0`으로 복원한다. `v1.7.0`으로 DB를 롤백해야 하는 경우에는 해당 버전의 migration 전 backup 복원 절차를 그대로 따른다.
