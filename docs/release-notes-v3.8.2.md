# AGS 3.8.2 릴리스 노트

2026년 11월 7일 공개한 AGS 3.8.2는 3.8.1의 하위 에이전트 단계 확인을 실행 주체 기준으로 다시 고친 수정판입니다. 데이터·공개 API 계약은 바꾸지 않으며 이관 작업은 필요 없습니다.

## 고친 결함

- **AGS3-D-0061**: 턴 끝 단계 확인을 세션 단위로만 판정해, 하위 에이전트가 만든 workflow의 남은 단계가 그 하위 에이전트에게 안내되지 않았습니다. 판정도 일부 호스트의 하위 에이전트 표지에만 기대고 있었습니다.
  - 단계 확인은 일을 한 실행 주체(메인 또는 각 하위 에이전트)의 것입니다. 하위 에이전트의 편집과 그 하위 에이전트가 시작하거나 연 workflow는 그 하위 에이전트가 끝날 때 확인하고, 부모의 Stop에서는 확인하지 않습니다.
  - Claude Code는 `SubagentStop`, Codex는 하위 에이전트의 `Stop`(`agent_id`)을 하위 에이전트의 턴 끝으로 봅니다. Claude Code 플러그인은 `SubagentStop` 훅을 새로 등록합니다.
  - Antigravity는 하위 에이전트의 훅이 자기 대화 ID로 들어옵니다. 하위 에이전트가 AGS 도구를 한 번 부르면 그 대화를 부모 세션의 하위 에이전트로 기록하고, 이후 그 대화의 편집과 턴 끝을 그 하위 에이전트의 것으로 판정합니다.
- **AGS3-D-0063**(3.8.1 회귀): 하위 에이전트가 직접 시작하거나 연 workflow 안의 편집이 범위 밖으로 세어져 세 번째 제품 파일부터 거부되던 문제를 고쳤습니다. 편집 관문은 다시 세션의 모든 결속 workflow를 봅니다.

## 알려진 제한

- Antigravity 하위 에이전트가 AGS 도구를 한 번도 부르지 않았으면 그 대화는 독립 세션으로 판정됩니다. workflow 없는 제품 파일 편집은 거부 안내가 나오며, 안내대로 workflow를 시작하면 그때부터 하위 에이전트로 판정됩니다.
