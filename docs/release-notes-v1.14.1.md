# v1.14.1 — 한국어 산문 선정 정책 수정

## 핵심 변경

- `korean-prose-editor`의 선정 정책에서 직역한 내부 구현 은유의 제외 범위를 좁힙니다. 제외 대상은 코드·백틱 구간, 스키마 필드, 고정 식별자, 사용자가 지정한 고정 문자열과 `protectedStrings`이며, 문서 전체가 기술 문서라는 사실은 제외 사유가 아닙니다.
- 같은 판정 기준에서 "기술 계약·코드·스키마를 설명하는 문맥"을 "정의하는 자리"로 좁히고, 문단이나 문서가 기술 계약을 다룬다는 사실만으로 제외하지 않는다고 명시합니다.
- 저장소 문서의 `영수증`·`결속` 직역 표현을 정리하고, README를 핵심 섹션만 남기도록 줄여 나머지 내용을 `docs/operations.md`와 `docs/development.md`로 옮깁니다. `README.en.md`도 같은 구조로 맞춥니다.

## 배경

이전 정책은 해당 규칙의 제외 목록에 "기술 문서"를 통째로 넣었습니다. 이 저장소의 문서는 모두 기술 문서이므로 규칙이 실제로 발동하지 않았습니다. 저장소 문서를 대상으로 실행했을 때 `전체 영수증` 같은 표현이 기술 문맥이라는 이유로 유지됐고, 같은 원문을 고친 정책으로 다시 판정하자 결함으로 분류됐습니다.

## 호환성

- 스킬 구성, 공개 계약 schema, SQLite schema는 v1.14.0과 같습니다.
- MCP 서버 동작과 Codex·Claude 배포물의 실행 경로는 바뀌지 않습니다.
- `korean-prose-editor`는 편입 스킬이므로 `skills/source-lock.json`의 `integratedChecksum`과 `downstreamModifications`를 갱신했습니다. 이전 checksum에 결속된 동결 평가 frame은 다시 동결해야 합니다.

## 알려진 제한

- 스킬을 직접 실행하는 경로는 계약대로 SQLite 용어집을 조회하지 않습니다. 용어집 정책이 판정에 결속되는 경로는 MCP 실행뿐입니다.
- 이번 정책 수정의 효과는 선정 단계 재실행 한 번으로 확인했으며, 동결 평가로 측정하지 않았습니다.
