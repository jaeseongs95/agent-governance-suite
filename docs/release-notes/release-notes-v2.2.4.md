# v2.2.4

로컬 메시지 브로커의 기동 실패가 이후 세션의 통신까지 계속 막는 문제를 수정했습니다.

- 접속 주소 파일을 교체할 때 일시적인 파일 잠금 오류가 나면 최대 750ms 동안 네 번 재시도합니다.
- 인증 파일, DB, 소켓 또는 주소 파일을 준비하다 실패하면 열린 연결, 서버, DB, 잠금과 이번 기동의 주소 임시 파일을 정리합니다. 아직 교체하지 못한 기존 주소 파일은 보존합니다.
- 실패한 브로커는 오류 코드만 표준 오류에 남기고 종료합니다. 비밀값과 메시지 본문은 기록하지 않습니다.
- 일시적·영구적 주소 게시 실패와 인증 파일·DB 초기화 실패, 실패 후 재기동을 설치용 번들로 검증하는 회귀 테스트를 추가했습니다.
- 기존 보안 감사 스킬의 출처 참조를 동일한 내용이 있는 공개 커밋으로 정정했습니다. 스킬 내용과 checksum은 바뀌지 않습니다.

메시지 프로토콜과 DB 스키마는 바뀌지 않습니다. 기존 메시지·인증 자료를 유지합니다. 이전 버전에서 이미 멈춘 브로커는 패치 설치 후 해당 프로세스를 재시작해야 하며, 설치 캐시를 삭제할 필요는 없습니다.

관측된 장애에서는 살아 있는 브로커의 잠금 PID와 접속 주소의 PID가 달랐고, 새 주소 임시 파일이 남아 있었습니다. 주소 교체 실패 뒤 소켓과 잠금을 유지하는 결함은 재현했습니다. 당시 파일 교체를 막은 외부 요인은 이전 버전이 오류를 기록하지 않아 확정하지 못했습니다.
