# v1.19.1 — 테스트 이식성 수정

## 핵심 변경

- `tests/mcp/stage-output-file.test.ts`의 네트워크 경로 거절 테스트가 Windows에서만 맞는 오류 문구를 기대해, v1.19.0의 CI가 Ubuntu 작업 두 개에서 실패했습니다. POSIX에서는 역슬래시 UNC 경로가 상대 경로로 해석돼 "절대 경로가 아니다"라는 이유로 먼저 거절됩니다. 두 운영체제 모두 거절한다는 동작은 같으므로, 테스트가 두 오류 문구를 모두 받도록 고쳤습니다.

## 호환성

- 서버, 스킬, 계약, 훅, 생성된 Claude 배포물의 동작은 v1.19.0과 같습니다. 바뀐 것은 테스트 한 줄과 버전 표기뿐입니다.
