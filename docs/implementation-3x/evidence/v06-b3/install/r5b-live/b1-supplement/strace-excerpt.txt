공유 라이브러리는 node DT_NEEDED 목록과 같다. 자식은 gpgv·tar·xz·검증 node(--version)이고, 각자의 시스템 라이브러리만 열었다.
결론: 기록된 openat 범위에서 주입 적재(preload 라이브러리, node_modules, NODE_OPTIONS 스크립트, 그 밖의 /home 파일)는 없다.
