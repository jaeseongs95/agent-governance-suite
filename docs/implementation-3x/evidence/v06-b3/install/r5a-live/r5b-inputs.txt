## 3. b3a input-dir 준비 (r5b에서 실행, r5a에서는 하지 않음)
- CLI는 입력 디렉터리에 정확한 네 파일 이름을 요구한다: node-v24.21.0-linux-x64.tar.xz, SHASUMS256.txt, SHASUMS256.txt.sig, nodejs-release-keyring.kbx
  (0f530615:docs/implementation-3x/evidence/v06-b3/archive/README.ko.md:23).
- 따라서 root 0700 input-dir을 만들고, pubring.kbx를 nodejs-release-keyring.kbx 이름으로 복사한다. 복사 뒤 sha256을 다시 대조한다.

## 4. 명령 형식 (0f530615 install/README.ko.md:173-175)
AGS_V06_B3B_PROTECTED_INSTALL=1 /root/r5a/node/bin/node scripts/qualification/v06-b3-linux-install.mjs \
  --base-dir /usr/lib --input-dir <root-only b3a input-dir> --gpgv /usr/bin/gpgv --tar /usr/bin/tar \
  --manifest /root/r5a-out/manifest.txt --package-source /root/r5a/src
(/root/r5a/node/bin/node의 sha256이 7fde7b8a…와 같은지 실행 직전에 확인한다. /opt/node22는 쓰지 않는다.)

## 5. 중단 조건 (하나라도 걸리면 설치하지 않고 BLOCKED로 보고)
- /usr/lib/agent-governance-suite가 이미 있다.
- /root/r5a-out/manifest.txt가 있거나, /root/r5a-out·조상이 root 700/755가 아니거나, symlink다.
- scratch-sha256.txt 검사가 실패하거나 목록 sha256이 다르다.
- 위 입력 sha256 중 하나라도 다르거나, gpgv가 GOODSIG·VALIDSIG 5BE8A3F6…를 내지 않는다.
- installer blob이나 코드 pin(TRUST_PINS, PINNED)이 위 값과 다르다.
- source에 g/o 쓰기·symlink·비root 소유·nlink>1 항목이 생겼거나, artifact digest가 하나라도 다르다.
- AREA_SESSIONS의 V writer가 이 세션이 아니거나 GO가 없다.
- /usr가 별도 mount가 되었거나, findmnt 경계가 preinstall-state.txt와 다르다.
