# 분산시스템

모듈 `distributed-systems` · v0.1.0 · 상태 `validated`



검증 범위: 핵심 규칙의 제한된 실행 참조 사례를 로컬에서 검사했다. 실제 대상의 구현 검증과 독립 감사는 별도다.



## DIST-ACK-001 — ACK와 부작용 경계

**원리:** 전송 수락·수신·지속 저장·업무 완료의 ACK를 구분한다.

**불변조건:** ACK가 의미하는 수준까지만 완료를 보고하고 재전송을 처리한다.

**적용 조건:** 메시지·콜백·원격 작업을 확인 응답한다.

**가정:** 요청과 허용된 대상의 실제 코드·운영 경계가 확인되어 있다.

**실패 형태:** 네트워크 send 성공을 상대 처리 완료로 기록한다.

**판단 질문:** ACK 전후 crash에서 무엇이 재전송되는가? / 실패와 결과 불명은 구분되는가?

**검증 의무:** 처리 직전·직후·ACK 직전 장애를 주입해 유실·중복·상태를 확인한다.

**하지 않을 일:** at-least-once 전달을 외부 효과 exactly-once라고 부르지 않는다.

**출처 식별자:** AWS-IDEMPOTENCY (`assets/sources.json`에서 범위와 원문 위치를 확인한다.)



## DIST-IDEMPOTENCY-002 — 멱등성 키의 의미

**원리:** 재시도와 새 의도를 구분하는 안정된 식별자를 유지한다.

**불변조건:** 같은 의도의 재시도는 계약된 보존 기간·경계 안에서 중복 효과를 억제한다.

**적용 조건:** 재시도가 외부 부작용을 일으킬 수 있다.

**가정:** 요청과 허용된 대상의 실제 코드·운영 경계가 확인되어 있다.

**실패 형태:** 재시도마다 새 키를 생성하거나 다른 payload에 같은 키를 쓴다.

**판단 질문:** key 보존 기간과 payload 일치 검사는 무엇인가? / 키 기록과 효과가 함께 확정되는가?

**검증 의무:** 동일 요청 재전송·다른 payload·늦은 재전송·처리 후 응답 유실을 검사한다.

**하지 않을 일:** 키 문자열 하나 추가한 것으로 멱등성을 증명하지 않는다.

**출처 식별자:** AWS-IDEMPOTENCY (`assets/sources.json`에서 범위와 원문 위치를 확인한다.)



## DIST-RETRY-003 — 부분 장애와 재시도 예산

**원리:** 재시도 가능한 실패·전체 deadline·횟수 상한을 함께 정의한다.

**불변조건:** 영구 실패나 부하 급증이 무한 재시도·폭증으로 전환되지 않는다.

**적용 조건:** 외부 의존성 실패 시 재시도한다.

**가정:** 요청과 허용된 대상의 실제 코드·운영 경계가 확인되어 있다.

**실패 형태:** 여러 계층이 각각 재시도해 시도 수가 곱으로 증가한다.

**판단 질문:** timeout은 미실행인가 결과 불명인가? / backoff·jitter·상위 예산은 무엇인가?

**검증 의무:** 부분 실패와 장기 장애에서 총 시도 수·부하·최종 원인을 확인한다.

**하지 않을 일:** 정합성 확인 없이 모든 timeout을 다시 보내지 않는다.

**출처 식별자:** HTTP-9110, AWS-IDEMPOTENCY (`assets/sources.json`에서 범위와 원문 위치를 확인한다.)



## DIST-ORDER-004 — 순서와 버전 단조성

**원리:** 도착 순서와 의미적 최신성을 분리한다.

**불변조건:** 오래된 알림이 새 상태를 되돌리거나 다른 epoch와 섞이지 않는다.

**적용 조건:** 상태 알림·이벤트가 지연·중복·역순 도착한다.

**가정:** 요청과 허용된 대상의 실제 코드·운영 경계가 확인되어 있다.

**실패 형태:** 늦게 도착한 이전 버전의 성공이 최신 실패를 덮어쓴다.

**판단 질문:** 버전은 어떤 범위에서 비교 가능한가? / 누락·재시작·epoch 변경은 어떻게 처리하는가?

**검증 의무:** 중복·역순·누락·새 epoch 입력을 섞어 상태가 정의된 순서를 따르는지 확인한다.

**하지 않을 일:** 전역 순서가 필요 없는데 합의 프로토콜을 추가하지 않는다.

**출처 식별자:** AGS-DESIGN (`assets/sources.json`에서 범위와 원문 위치를 확인한다.)
