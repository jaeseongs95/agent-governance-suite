# 공급자별 확인 사항

이 문서는 공통 프롬프트를 특정 모델에 연결할 때만 읽어라. 제품명·모델·API 지원은 변할 수 있으므로 실제 설치·공식 문서에서 확인하라. 과업 의미·근거·출력 계약은 같게 유지하되 호스트가 지원하는 전달 형식에 맞춰라.

| 계열 | 확인할 것 | 적용 방법 |
| --- | --- | --- |
| OpenAI | reasoning 지원, 실제 메시지 역할, structured output, 도구 계약 | 명료한 직접 지시로 시작하고 필요한 경우 예시 추가. 내부 사고 과정 전체를 요구하지 않음 |
| Anthropic | 현재 모델의 지시 해석, 메시지 역할, 긴 문서·도구 결과 처리 | 관련성·다양성이 있는 예시와 명확한 자료 구획 사용. 추가 호출·별도 보안 모델을 자동 도입하지 않음 |
| Google | 현재 모델의 예시 활용, 응답 schema, 지원되는 generation parameter | 일관된 예시와 형식을 실제 실패에 맞게 비교. 매개변수 지원을 확인한 뒤 조정 |
| 다른 공급자·호스트 | 가용 모델, 역할, 도구, 최대 입력, 출력 강제 기능 | 같은 의미 계약을 기존 adapter로 연결. 지원하지 않는 기능은 미지원으로 남김 |

`temperature=0`, 특정 effort, 예시 개수, 영어 프롬프트를 모든 모델에 강제하지 마라. API 지원이 데스크톱·구독 호스트에도 노출된다고 가정하지 마라. 품질·지연·캐시 hit는 실제 기록으로 비교하라.

공통 스킬은 특정 모델 ID·SDK·계정·API 키가 없어도 설계 작업을 할 수 있어야 한다. 모델 선택·실행 경로는 기존 AGS 담당과 adapter가 소유한다.
