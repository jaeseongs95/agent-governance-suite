# D0040 genuine legacy upgrade 필수 회귀

기존 CI collector가 양 OS의 shard 1에서 한 번씩 필수 실행한다. 다른 shard에는 old source 설치를 하지 않는다. 기존 workflow, nonce, deadline, artifact cap, 실패 보존 규칙은 유지한다.

old는 b3285616c896afdcbb298e3a08dffd612ddfa7b8 / tree 797ccf5960fea8fcebe16025d7786ca389ab6fbc 전체 1733 Git blob이다. current는 실제 triggering GITHUB_SHA 전체 Git blob이다. collector가 실제 checkout/HEAD/tree와 모든 blob OID·size를 검산해 만든 두 manifest의 SHA-256를 runner의 별도 argv로 전달한다. JSON 입력의 자기 선언만으로 검증하지 않는다. historical c3 고정 실행 증거는 AL06의 이전 packet에 그대로 보존한다.

두 source 모두 각 frozen lockfile로 정확 pnpm 11.19.0 의존성을 준비한다. Node 24, manifest/pin/source/deps 중 하나라도 없거나 다르면 실패하며 skip/fallback은 없다.

```sh
node validation/run-upgrade-test.mjs INPUT_JSON EXPECTED_CURRENT_HEAD CURRENT_MANIFEST_SHA256 OLD_MANIFEST_SHA256
```

외부 검산된 pin을 공급하는 collector에서 실행한다. 로컬 author는 같은 전체 source 검산을 먼저 수행하고 명시 Environment.Clear/whitelist launcher를 사용한다. evidenceDirectory는 새 경로여야 한다. 현재 source 검사는 build 전에 실행하여 generated bytes의 provenance도 보존한다.

실제 old API가 생성한 키와 원 HMAC을 사용하고 같은 SQLite를 close/reopen한다. test harness는 키를 조회·수정하거나 재서명하지 않는다. synthetic task와 registry이며 실제 운영 legacy 데이터는 아니다. missing phase/HMAC 순서, 거부 후 history 불변, 원 plan bytes 보존, 같은 root ordinal 2의 explicit PRE를 검증한다. 별도 위조 negative는 memory copy일 뿐 원 plan이 아니다.
