# Editing policy

selection 결과에 포함된 범위만 수정한다. 원문과 문체 샘플에 없는 사실이나 표현상의 확신을 보태지 않는다. 보호 구간과 겹치는 edit는 만들지 않는다.

각 edit는 서로 겹치지 않는 `[start, end)` 범위와 replacement로 표현한다. 여러 안전한 수정과 불확실한 수정이 섞여 있으면 안전한 수정만 제안한다. 문장을 합치거나 나눌 때는 주어, 부정, 조건, 인과, 시간 관계와 병렬 구조를 다시 대조한다.

검증자의 결정을 예상하거나 verification 결과를 작성하지 않는다.
