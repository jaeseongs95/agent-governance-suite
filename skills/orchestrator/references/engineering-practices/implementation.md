# implementation

이 모듈이 필요한 작업에서만 읽는다. 기존 AGS 권한·역할·계약을 유지한다. 규칙 원본은 [catalog.json](catalog.json)이며 모델 행동 평가는 NOT_RUN이다.

## IMP-001 — 가장 작은 올바른 변경

**담당:** ponytail

**적용:** 구현·리팩토링

**행동:** 요구와 필수 제약을 만족하는 최소 변경을 고르고 무관한 정리는 분리한다.

**근거:** 변경 파일마다 요구 또는 필수 제약과의 연결을 남긴다.

**피할 실패:** 짧게 만들기 위해 검증·권한·복구 조건을 삭제하지 않는다.

**예외:** cs-engineering이 도출한 불변조건은 단순화 대상이 아니라 만족할 조건이다.

출처: AW-REVIEW, AW-TEST ([고정 커밋](sources.lock.json)).

## IMP-002 — 추상화의 사용처 확인

**담당:** ponytail

**적용:** 공통 인터페이스·설계 패턴을 추가할 때

**행동:** 실제 둘 이상의 사용처 또는 명확한 변화 축을 확인하고 기존 모듈 경계로 해결되는지 비교한다.

**근거:** 현존 호출자와 제거되는 중복 책임을 기록한다.

**피할 실패:** 미래에 필요할 수 있다는 말만으로 framework를 추가하지 않는다.

**예외:** 공개 확장 계약이 현재 요구라면 단일 구현이어도 인터페이스가 필요할 수 있다.

출처: AW-REVIEW, AW-TEST ([고정 커밋](sources.lock.json)).

## IMP-003 — 오류 의미 보존

**담당:** ponytail

**적용:** 예외·오류·재시도를 수정할 때

**행동:** 호출자가 구별해야 할 실패를 보존하고 재시도는 부작용·상한·취소 조건과 함께 정한다.

**근거:** 오류별 외부 동작과 재시도 가능한 조건을 테스트한다.

**피할 실패:** 모든 예외를 성공 값으로 바꾸거나 무한 재시도로 숨기지 않는다.

**예외:** 상세 원인 공개는 신뢰 경계에 맞추고 비밀은 오류 문자열에 넣지 않는다.

출처: AW-REVIEW, AW-TEST ([고정 커밋](sources.lock.json)).

## IMP-004 — 자원 수명과 취소

**담당:** ponytail

**적용:** 파일·연결·프로세스·stream 사용

**행동:** 성공·오류·timeout·취소의 모든 경로에서 소유자가 자원을 해제하도록 구현한다.

**근거:** 해제 관측 또는 종료 후 상태 검사를 남긴다.

**피할 실패:** 정상 경로에서만 close하는 코드로 완료하지 않는다.

**예외:** 외부 프로세스 트리 종료는 호스트 지원을 확인하고 임의의 광범위 kill을 사용하지 않는다.

출처: AW-REVIEW, AW-TEST ([고정 커밋](sources.lock.json)).

## IMP-005 — 배포 단위를 검증

**담당:** ponytail

**적용:** 번들·CLI·스킬·패키지 변경

**행동:** 개발 트리와 설치 트리의 import·경로·의존성을 구분하고 배포와 같은 사본에서 검사한다.

**근거:** node_modules 없는 clean-room 검사와 산출물 digest를 남긴다.

**피할 실패:** 소스 테스트만으로 실제 설치와 자동 호출까지 성공했다고 하지 않는다.

**예외:** 기존 AGS 번들·Claude 생성물은 공식 생성 경로로만 갱신한다.

출처: AW-REVIEW, AW-TEST ([고정 커밋](sources.lock.json)).

## IMP-006 — 로그는 판별 가능한 최소 정보

**담당:** ponytail

**적용:** 디버그 로그나 예외 메시지를 추가할 때

**행동:** 작업 ID·상태 전이·에러 코드·소요 시간 등 판별에 필요한 구조화 필드를 사용한다.

**근거:** 필요한 필드와 민감정보 제외 검사를 남긴다.

**피할 실패:** 비밀번호·토큰·고객 원문·환경 전체를 로그에 쌓지 않는다.

**예외:** 로그 유무만으로 처리 성공을 판단하지 않고 실제 상태와 대조한다.

출처: AW-REVIEW, AW-TEST ([고정 커밋](sources.lock.json)).
