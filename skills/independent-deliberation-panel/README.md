# Independent Deliberation Panel

복잡하거나 실패 비용이 큰 판단을 원안에서 독립된 제3자 관점으로 검토하고, 실제 쟁점을 논쟁한 뒤 증거와 판정축을 기준으로 합의 가능성과 실행안을 판단하는 Codex 스킬입니다. 의견 수를 채우는 대신 각 관점이 무엇을 실패로 보는지 분명히 나누고, 확인된 근거와 남은 불확실성을 구별합니다. 공통안을 만들 수 없으면 조건부 합의나 합의 불가 사유를 그대로 제시합니다.

## 언제 쓰나요

다음과 같이 한 번의 낙관적인 검토만으로 결정하기 어려운 요청에 맞습니다.

- 시스템 설계나 아키텍처의 중요한 선택을 검증할 때
- 보안, 운영, 계약, 사용자 경험처럼 서로 충돌할 수 있는 기준을 함께 판단할 때
- 되돌리기 어렵거나 실패 비용이 큰 결정을 내릴 때
- 기존 AI 분석이나 제안서를 독립적으로 감사할 때
- 복잡한 장애 원인이나 여러 해석이 가능한 데이터를 검토할 때

사실 조회, 짧은 요약, 단순 계산, 문법 수정, 정형 변환처럼 여러 관점의 반박이 결과를 실질적으로 개선하지 않는 요청에는 사용하지 않습니다.

## 설치

Git이 설치된 Windows 환경에서 다음 명령을 실행합니다. `<USER>`는 Windows 사용자 이름으로 바꾸세요.

```powershell
git clone https://github.com/jaeseongs95/independent-deliberation-panel "C:\Users\<USER>\.codex\skills\independent-deliberation-panel"
```

## 사용

스킬을 직접 지정하려면 요청에 `$independent-deliberation-panel`을 넣습니다.

```text
$independent-deliberation-panel을 사용해 이 인증 아키텍처의 출시 여부를 보안, 운영, 사용자 경험 관점에서 검토해 줘.
```

```text
$independent-deliberation-panel로 이 마이그레이션 계획을 제3자 관점에서 논쟁하고, 합의안과 미해결 위험을 구분해 줘.
```

자동 호출이 켜져 있어 스킬 이름을 쓰지 않아도 복잡하거나 고위험인 판단 요청에는 선택될 수 있습니다. 단순 요청은 일반 처리로 남습니다.

## 어떻게 동작하나요

요청의 복잡도와 실패 영향을 먼저 분류한 뒤, 필요한 경우 서로 다른 실패 관점을 가진 검토자들이 독립적으로 분석합니다. 결론에 영향을 주는 충돌이나 미검증 전제가 있으면 핵심 주장을 교차 반박합니다. 독립 관점들이 이미 근거상 수렴해 실제 쟁점이 없을 때만 반박을 생략하고 그 이유를 기록합니다. 실제 파일, 테스트 결과, 공식 문서를 대조한 뒤 다수결이나 신뢰도 평균이 아닌 합의 상태, 실행안, 판정축별 결론과 남은 이견을 제시합니다. 필수 조건이 양립하지 않으면 합의를 만들어내지 않습니다.

## 권한과 비용

이 스킬을 호출해도 파일 수정, 배포, 외부 메시지 전송 같은 권한이 새로 생기지는 않습니다. 실제 작업은 사용자가 원래 요청에서 허용한 범위 안에서만 수행합니다.

복잡도가 높을수록 여러 검토자와 별도 판정자를 사용할 수 있어 단일 분석보다 시간과 모델 사용량이 늘어날 수 있습니다. 스킬은 단순 요청을 조기에 분리하고, 새 근거 없이 같은 반박을 반복하지 않도록 범위를 제한합니다.
