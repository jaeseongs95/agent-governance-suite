# 알고리즘·자료구조

모듈 `algorithms-data-structures` · v0.1.0 · 상태 `validated`



검증 범위: 핵심 규칙의 제한된 실행 참조 사례를 로컬에서 검사했다. 실제 대상의 구현 검증과 독립 감사는 별도다.



## ALG-TERMINATION-001 — 탐색의 종료와 방문 상태

**원리:** 진행 척도와 이미 처리한 상태를 명시한다.

**불변조건:** 유한한 입력에서 순회는 종료하고 필요한 노드를 빠뜨리지 않는다.

**적용 조건:** 의존성·상태·호출 그래프를 순회한다.

**가정:** 요청과 허용된 대상의 실제 코드·운영 경계가 확인되어 있다.

**실패 형태:** 순환을 방문 표시 없이 재귀 순회하면 종료하지 않는다.

**판단 질문:** 노드와 상태의 동일성은 무엇인가? / 방문 표시는 확장 전인가 후인가? / 스택 깊이의 상한은 있는가?

**검증 의무:** 자기 순환·다중 순환·분리 그래프·긴 사슬을 넣고 종료 및 방문 집합을 확인한다.

**하지 않을 일:** 일반 그래프에 DAG 가정을 숨기지 않는다.

**출처 식별자:** MIT-ALGORITHMS (`assets/sources.json`에서 범위와 원문 위치를 확인한다.)



## ALG-ORDER-002 — 위상 순서와 순환 거부

**원리:** 성공한 순서는 모든 선행 간선을 보존해야 한다.

**불변조건:** 각 간선 u→v에서 u가 v보다 먼저 처리되고 순환은 명시적으로 거부된다.

**적용 조건:** 의존성을 만족하는 실행 순서를 계산한다.

**가정:** 요청과 허용된 대상의 실제 코드·운영 경계가 확인되어 있다.

**실패 형태:** Kahn 처리 결과가 일부뿐인데 정상 순서라고 반환한다.

**판단 질문:** 중복 간선과 미등록 노드는 어떻게 처리하는가? / 동점의 결정성이 요구되는가?

**검증 의무:** 생성한 DAG의 모든 간선을 대조하고 순환·누락 노드 입력은 실패시킨다.

**하지 않을 일:** BFS 순서를 위상 정렬이라고 부르지 않는다.

**출처 식별자:** MIT-ALGORITHMS (`assets/sources.json`에서 범위와 원문 위치를 확인한다.)



## ALG-COST-003 — 입력 크기와 비용 모델

**원리:** n, 간선 수, 데이터 접근 비용을 따로 계산한다.

**불변조건:** 선택한 자료구조와 알고리즘의 비용이 실제 입력 규모의 목표를 충족한다.

**적용 조건:** 탐색·중복 제거·정렬의 비용이 중요하다.

**가정:** 요청과 허용된 대상의 실제 코드·운영 경계가 확인되어 있다.

**실패 형태:** 배열 membership를 매번 선형 검색해 중복 제거가 제곱 비용이 된다.

**판단 질문:** 최악·평균·상각 중 어느 주장인가? / I/O 비용이 연산 비용보다 큰가?

**검증 의무:** 크기를 두 배씩 키워 연산 횟수·메모리·시간을 측정하고 작은 입력의 역전도 확인한다.

**하지 않을 일:** Big-O만으로 실제 지연 개선을 선언하지 않는다.

**출처 식별자:** MIT-ALGORITHMS (`assets/sources.json`에서 범위와 원문 위치를 확인한다.)



## ALG-KEY-004 — 동일성과 메모이제이션

**원리:** 키는 결과를 바꾸는 모든 입력과 버전을 표현해야 한다.

**불변조건:** 동일 키의 재사용이 현재 작업 계약에서 결과를 바꾸지 않는다.

**적용 조건:** 캐시·집합·해시로 계산을 생략한다.

**가정:** 요청과 허용된 대상의 실제 코드·운영 경계가 확인되어 있다.

**실패 형태:** 목표·설정·권한 버전이 다른 요청에 같은 캐시 키를 쓴다.

**판단 질문:** 참조 동일성과 값 동일성이 일치하는가? / 충돌 확인과 무효화 조건은 있는가?

**검증 의무:** 키의 각 의미 입력을 바꿔 누락을 검출하고 충돌·만료·메모리 상한을 시험한다.

**하지 않을 일:** 비밀 원문을 캐시 키나 로그에 기록하지 않는다.

**출처 식별자:** MIT-ALGORITHMS, AGS-DESIGN (`assets/sources.json`에서 범위와 원문 위치를 확인한다.)
